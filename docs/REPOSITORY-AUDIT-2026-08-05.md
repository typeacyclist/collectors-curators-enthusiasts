# Repository Retirement Audit — 2026-08-05

## Scope

- `cce-orchid-mvp/`
- `docs/`
- `docs/architecture/`

The review used the authoritative governance document and ADR-001, ADR-002, and ADR-003 as the decision basis.

## Classification standard

Each item was classified as:

- **Current** — aligned with the accepted Firebase-native architecture and current product scope.
- **Retired** — implements or documents a superseded runtime, generated artifact, or obsolete deployment path.
- **Consolidated** — useful content retained through a smaller current entry point or authoritative source.

Git history is the archive for retired implementation material. Retired code is not retained in an active source folder because doing so increases the risk of accidental extension, dependency scanning noise, and mistaken deployment.
